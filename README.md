# Uniovi Robotics Workshop GenAI

Este repositorio contiene el código y los recursos para el taller "Uniovi Robotics Workshop GenAI".

## Pruebas de Concepto (PoC)

El proyecto incluye las siguientes tres pruebas de concepto:

### 1. poc1-senoide
Prueba de concepto en **Python** para generar una senoide. Permite configurar y pasar parámetros de **amplitud**, **frecuencia** y **color** directamente desde la consola.

### 2. poc2-bienvenida
Prueba de concepto que implementa un proyecto tipo monorepo con un backend en **Python** y un frontend en **Angular**.
- El backend expone un endpoint que devuelve un mensaje de bienvenida.
- El frontend consume este endpoint y visualiza el resultado en una interfaz web.

### 3. poc3-senoide-matlab
Prueba de concepto en donde se utiliza el **motor de MATLAB** para poder dibujar igualmente una senoide, de forma similar a la primera PoC.

## Requisitos y Herramientas Mínimas

Para poder ejecutar y editar el código fuente de estas pruebas de concepto, es necesario disponer de las siguientes herramientas:

- **Python 3.11+**
- **Visual Studio Code** (o un editor de código similar)
- **Git** y acceso a **GitHub**
- **Antigravity** (versión TUI o escritorio instalada)
- Node.js y Angular CLI (necesarios para levantar el frontend de la `poc2`)
- MATLAB instalado (necesario para la `poc3`)

## Requisitos Visual Studio
